The 4-Tier Inclusive Access Continuum

Designed specifically to ensure 100% coverage across the socio-economic and digital divide in Bangladesh:

Tier 0
📄

No Device / Illiterate

Physical Paper Auto-Bridging

  • Bangla OCR Parsing: Local UDC scanners auto-ingest handwritten forms without data entry burden.
  • Full Digital Parity: Zero smartphone requirement for impoverished rural citizens.

📞

Button Phone / 2G

16430 Hotline Modernization

  • Zero-Data USSD (*16430#): Instant status tracking and emergency callback request.
  • SMS Milestones: Push notifications at every court hearing and lawyer assignment.

Comprehensive Technology Comparison Matrix

Why we selected our specific technologies over common industry alternatives:

Component Tier Final Selection Evaluated Candidates Why Selected (Strengths) Why Discarded (Weaknesses)
⚙️ Backend Core ERP
Java (Spring Boot 3) + Flowable BPMN Node.js (NestJS), Python (Django), Go, Ruby on Rails Enterprise ACID Reliability: Strict transactional integrity for legal evidence; native Flowable BPMN workflow execution for statutory Registers 01-09. Node.js: Lacks robust native BPMN engines and CPU intensive capabilities; Django: Slower concurrency for multi-district transactional loads.
🤖 AI & Voice Microservices
Python (FastAPI) + Fine-tuned Whisper Cloud OpenAI API Only, Flask, Node.js Local Dialect Adaptation: Supports self-hosted quantized models fine-tuned on Sylheti and Chittagonian dialects; async high-throughput inference; strict data privacy. Cloud OpenAI Only: Violates state data sovereignty for confidential criminal records; recurring dollar billing unsustainable for government budget; fails offline.
🗄️ Database & Geospatial
PostgreSQL 16 + PostGIS MongoDB, MySQL 8, CouchDB Strict Relational Schemas: Enforces statutory foreign keys between Beneficiary, Panel Lawyer, Hearing, and Statutory Registers; PostGIS performs instant polygon distance matching for Sec 15 allocation. MongoDB: Document stores lack rigid relational constraints, leading to data corruption in audit-critical judicial registers; weak geospatial polygon intersection for mouza maps.
📱 Frontend & Mobile
Progressive Web App (PWA) + Vanilla/React Flutter Mobile App, React Native Zero Install Friction: Sub-2MB bundle loads instantly via link or QR code; IndexedDB offline persistence allows field paralegals in char areas to work with zero network. Flutter: Requires 20MB+ Play Store download; in rural Bangladesh where phone storage is constrained and mobile data costs money, app-store requirement causes 80%+ drop-off.
📞 Telephony & PBX (16430)
FreeSWITCH / Asterisk PBX Core Twilio API SaaS, Agora, Vonage Sovereign Zero-Per-Minute Cost: Hosted on government cloud; direct SIP interconnection with local telecom carriers (Teletalk, Grameenphone, Robi); zero recurring SaaS fees. Twilio: Foreign SaaS creates sovereign privacy breach for national emergency calls; pay-per-minute USD billing creates massive foreign exchange drain on public funds.
🔒 Security & Bail Dispatch
OpenSSL X.509 PKI + AES-256 Unsigned PDF via Email, Courier Cryptographic Non-Repudiation: Judicial digital signature verifiable offline at prison gate terminal via high-density QR hash; eliminates fake bail releases and paper couriers. Unsigned Email/Courier: Takes 7–21 days to transit, highly vulnerable to forgery, corrupt middlemen, and unauthorized detainee detention.

Architectural Decision Records (ADRs)

Formal engineering decisions recorded for future developers and judicial stakeholders:

ADR-001

Sovereign Telephony Architecture for National 16430

Status: Approved • Driver: Data Sovereignty & Telecom Interconnect

Context: National legal helpline (16430) requires IVR, USSD capabilities, and dialect-specific speech-to-text without recurring USD cloud costs.

Decision: Deploy open-source FreeSWITCH PBX integrated with BTRC-authorized SIP trunks and custom Python AGI for AI voicebot processing.

ADR-002

Dual Microservices: Spring Boot ERP + FastAPI ML

Status: Approved • Driver: Performance Separation of Concerns

Context: Relational legal registers require ACID database locking, while voice transcription and OCR require high-throughput GPU/CPU execution.

Decision: Decouple into a Java Spring Boot transactional core and a Python FastAPI intelligence suite communicating via an asynchronous event bus.

ADR-003

PostgreSQL + PostGIS for Geospatial Panel Allocation

Status: Approved • Driver: Section 15 Proximity & Mouza Cadastral Maps

Context: Section 15 of Legal Aid Act requires matching victims to nearby lawyers within Upazilas, while Bhoo-Chitra requires spatial polygon matching for land plots.

Decision: Utilize PostgreSQL with PostGIS spatial indexing for sub-millisecond distance and cadastral boundary intersection calculations.

ADR-004

Sub-2MB Offline-First PWA over Native App Store Bundles

Status: Approved • Driver: Rural Device Storage & Connectivity

Context: Rural field workers and paralegals frequently lose cellular connectivity in riverine char regions and use entry-level Android devices.

Decision: Build a Progressive Web App utilizing Service Workers and IndexedDB for local offline queuing with automatic background synchronization.
